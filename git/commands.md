# Git Commands Reference

A collection of commonly used Git commands and their purposes.


`git init                  Initialize a Git repository 
`git clone URL             Clone a remote repository 
`git status                Check the current repository status 
`git add .                 Stage all changes 
`git commit -m "message"   Commit staged changes 
`git log 	           View commit history 
`git branch 	           List branches 
`git switch branch-name    Switch branches 
`git merge branch-name     Merge a branch 
`git remote -v             View remote repositories 
`git push                  Upload commits to a remote repository 
`git pull                  Fetch and integrate remote changes 
`git fetch                 Download remote updates without merging
