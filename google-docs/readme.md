# Google Docs

Google Docs is an online document editor. In the course work, I explored how to create documents, format their contents and share them with other people. It is useful when a document needs to be accessed from different devices or edited collaboratively.

## Creating and organising a document

I explored the interface and the basic options for creating and managing documents. Using headings gives a document a clear structure and makes longer content easier to navigate.

## Formatting content

The formatting work included:

- Changing font styles, sizes and colours.
- Adjusting paragraph alignment and spacing.
- Applying headings to organise sections.
- Creating bulleted and numbered lists.

I learned that consistent formatting usually makes a document easier to read than using too many different styles.

## Page layout and inserted content

I also explored inserting tables, images and links, adding headers and footers, and adjusting page margins and layout. These options help organise information and prepare a document for its intended use.

## Sharing and collaboration

Google Docs allows a document to be shared with different permission levels:

- **Viewer** can read the document.
- **Commenter** can read the document and leave comments.
- **Editor** can make changes.

Comments and suggestions make it easier to discuss edits, while real-time collaboration allows multiple people to work on the same document.

## What I learned

The main thing I learned is that formatting is not just about appearance. A clear structure, consistent spacing and appropriate sharing permissions make a document easier to use and work on with others.
